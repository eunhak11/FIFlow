01
프로젝트 개요
FIFlow는 외국인 투자자의 순매수/순매도 동향과 주요 지수(KOSPI, KOSDAQ, KPI200)를 실시간으로 모니터링하는 개인용 금융 모바일 앱이다. v1의 핵심 실패 원인인 콜드 스타트 지연과 실시간 데이터 불일치를 v2에서 구조적으로 해결한다.
항목내용
서비스명FIFlow v2 (Foreign Investor Flow)
서비스 유형개인용 금융 정보 모바일 앱 (PWA)
주요 타겟국내 주식 투자자 (1인, 개인용)
핵심 가치외국인 투자 동향 + 지수 실시간 모니터링
플랫폼모바일 웹 PWA (홈 화면 추가 시 네이티브 앱처럼 동작)
인증카카오 소셜 로그인 (NextAuth.js)

06
주요 기능 명세
F-01 · 인증 시스템
카카오 소셜 로그인 / 세션 관리
NextAuth.js + 카카오 Provider를 사용하여 OAuth 2.0 인증을 구현한다. 미들웨어가 모든 경로를 보호하며, 비로그인 접근을 /login으로 리다이렉트한다.
  • MUST카카오 디벨로퍼스 OAuth APP_KEY, APP_SECRET 환경변수 설정
  • MUST로그인 성공 시 NextAuth session을 생성하고 브라우저에 저장
  • MUSTNext.js 미들웨어에서 세션 없는 접근을 /login으로 리다이렉트
  • MUST서버 컴포넌트에서 getServerSession(), 클라이언트에서 useSession() 사용
  • MUST로그아웃 시 NextAuth signOut()으로 세션 완전 삭제
  • MUST최초 로그인 시 users 테이블에 kakao_id, email, nickname INSERT
  • SHOULD재로그인 시 users 테이블 중복 처리 (ON DUPLICATE KEY UPDATE)
F-02 · 지수 실시간 표시
KOSPI / KOSDAQ / KPI200 SSE 실시간 갱신
Python 프로세스가 KIS WebSocket을 구독하여 MySQL에 지수 데이터를 저장하고, Next.js SSE 엔드포인트가 MySQL을 폴링하여 클라이언트에 push한다.
  • MUSTPython kis_websocket.py가 KIS WebSocket으로 KOSPI, KOSDAQ, KPI200 구독
  • MUST수신 데이터를 MySQL index_data 테이블에 upsert (ON DUPLICATE KEY UPDATE)
  • MUST/api/sse/index 엔드포인트가 MySQL을 1초 간격 폴링, 변경 시 SSE 이벤트 전송
  • MUST클라이언트 EventSource로 구독, 연결 끊김 시 자동 재연결
  • MUSTSSE 헤더: Content-Type: text/event-stream, Cache-Control: no-cache
  • SHOULD장 시간(09:00-15:30 KST, 평일) 외에는 마지막 데이터를 유지 표시
  • SHOULD라이브 도트(●) 애니메이션으로 실시간 연결 상태 표시
F-03 · 관심 종목 관리
종목 추가 / 삭제 / 즐겨찾기 / 시세 조회
사용자가 종목 코드로 관심 종목을 등록하면 KIS API로 종목명을 자동 조회한다. KIS REST API로 30초마다 현재가를 갱신하며, 즐겨찾기 종목은 항상 상단에 고정된다.
  • MUST종목 코드 입력 → /api/stocks/price로 KIS API 종목명 조회 → DB 저장
  • MUST관심 종목 현재가를 30초마다 KIS REST API로 갱신 (Rate Limit 준수)
  • MUST★ 즐겨찾기 토글 → watchlist.is_favorite UPDATE → 목록 상단 고정
  • MUST종목 삭제 시 MySQL watchlist DELETE, 관련 외국인 데이터는 유지
  • SHOULD종목 카드에 등락 뱃지(▲▼) 빨강/파랑 색상 표시
  • NICE종목 코드 자동완성 (KIS API 종목 목록 기반)
F-04 · 외국인 순매매 동향
8거래일 순매수/순매도 바 차트
Python 크롤러가 평일 16:30에 네이버 금융에서 외국인 순매매 데이터를 수집한다. 각 관심 종목 카드 하단에 최근 8거래일 바 차트를 표시한다.
  • MUSTforeign_crawler.py가 평일 16:30 cron으로 네이버 금융 스크래핑
  • MUST수집 데이터를 MySQL foreign_trading 테이블에 upsert (ON DUPLICATE KEY UPDATE)
  • MUST관심 종목별 최근 8거래일 데이터를 /api/foreign-trading 엔드포인트로 제공
  • MUST순매수(양수): 빨간색 막대 (중간선 기준 위 방향)
  • MUST순매도(음수): 파란색 막대 (중간선 기준 아래 방향)
  • MUST수치를 K/M 단위로 축약 표시 (+2.8M, -450K)
  • SHOULD데이터 없는 날(주말, 공휴일)은 차트에서 건너뜀
F-05 · SSE 엔드포인트
/api/sse/index — 서버 → 클라이언트 실시간 Push
서버가 MySQL을 폴링하여 변경된 지수 데이터를 SSE로 클라이언트에 전송한다.
  • MUST응답 헤더: Content-Type: text/event-stream, Cache-Control: no-cache, Connection: keep-alive
  • MUST1초 간격으로 MySQL index_data 조회, 변경 시 data: JSON 형식으로 전송
  • MUST클라이언트 연결 종료 감지 시 폴링 루프 종료 (메모리 누수 방지)
  • MUSTNext.js App Router Route Handler (GET) 로 구현
  • SHOULD클라이언트 재연결 시 즉시 현재 데이터 전송 (초기 로드 깜빡임 방지)
F-06 · Admin API
크롤러 수동 트리거 및 상태 조회
개발자가 외부에서 크롤러를 수동으로 실행하고 상태를 확인할 수 있는 API를 제공한다. X-Admin-Key 헤더로 인증한다.
  • MUSTPOST /api/admin/crawl/foreign — 외국인 순매매 크롤러 수동 실행
  • MUSTGET /api/admin/crawl/status — 마지막 크롤링 시각, 수집 건수, 상태 반환
  • MUSTX-Admin-Key 헤더 검증 (환경변수 ADMIN_API_KEY와 비교)
  • SHOULD실행 결과(성공/실패, 소요 시간, 수집 건수)를 JSON으로 반환
  • SHOULD실행 로그를 /home/fiflow/logs/crawler.log에 기록
F-07 · PWA
홈 화면 추가 — 네이티브 앱 경험
next-pwa를 통해 모바일에서 홈 화면에 추가 시 네이티브 앱처럼 동작한다.
  • MUSTmanifest.json: name, short_name, icons, display: standalone 설정
  • MUST홈 화면 추가 시 스플래시 화면, 풀스크린, 앱 아이콘 적용
  • SHOULDService Worker로 정적 자산 캐싱 (오프라인 시 마지막 화면 표시)
  • NICEiOS Safari 홈 화면 추가 배너 안내
